# Comandos Git e GitHub

## 📖 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar e consolidar conhecimentos sobre Git e GitHub, ferramentas essenciais para o controle de versão e gerenciamento de código-fonte.

Além da implementação de pequenos exercícios de programação, o foco principal foi a utilização prática dos comandos mais importantes do Git, simulando o fluxo de trabalho utilizado por desenvolvedores em projetos reais.

Durante o desenvolvimento foram realizados diversos testes envolvendo criação de repositórios, commits, gerenciamento de branches, sincronização com repositórios remotos e acompanhamento da evolução do código.

## 🎯 Objetivos

* Aprender e praticar os principais comandos do Git.
* Utilizar o GitHub para hospedagem e gerenciamento do projeto.
* Compreender o funcionamento do controle de versão.
* Desenvolver boas práticas de organização de código.
* Ganhar experiência com ferramentas utilizadas no mercado de tecnologia.

## 🛠️ Tecnologias e Ferramentas

* Git
* GitHub
* Terminal / Prompt de Comando
* Linguagem de Programação utilizada no projeto

## 📚 Conceitos Praticados

Durante o desenvolvimento foram aplicados conceitos como:

* Inicialização de repositórios.
* Criação e gerenciamento de commits.
* Adição e remoção de arquivos rastreados.
* Sincronização entre repositório local e remoto.
* Gerenciamento de branches.
* Controle e histórico de versões.
* Organização de projetos utilizando GitHub.

## 💻 Exemplos de Comandos Utilizados

```bash
git init
git clone
git status
git add .
git commit -m "mensagem"
git push
git pull
git branch
git checkout
git merge
git log
```

## 🚀 Aprendizados

Este projeto representou uma etapa importante no processo de aprendizado sobre versionamento de código. Através da prática constante dos comandos do Git foi possível compreender melhor como registrar alterações, acompanhar a evolução de um projeto e manter o código organizado de forma profissional.

Além do conhecimento técnico adquirido, o projeto contribuiu para o desenvolvimento de habilidades fundamentais para qualquer programador, como organização, controle de mudanças e utilização de ferramentas colaborativas amplamente adotadas pela indústria de software.

## 📈 Importância do Projeto

Embora seja um projeto de estudos, ele serviu como base para o entendimento de conceitos que serão utilizados em projetos maiores e mais complexos. O domínio do Git e do GitHub é uma habilidade indispensável para desenvolvedores modernos, tornando este projeto uma etapa importante na formação prática em desenvolvimento de software.
